ホームプライバシー利用説明

取得データと用途

Google Calendarから予定の日時、ID、UID、繰返し情報、状態、取得版、表示が許可された件名と元予定への導線を取得します。集計用の取得はdescription・location・参加者・添付を除外します。書込み先「移動・宿泊」の管理ID・手動変更の判定では必要なevent fieldsをメモリ内で照合し、raw本文・参加者・添付をGitや確認一覧へ転載しません。個人Googleと本人が許可した共有大学カレンダーを明示して取得し、見えている他人・家族のカレンダーを自動採用しません。

Google Sheetsから既存旅程一覧の指定範囲を読み、旅程・移動区間・宿泊のID、日程、手配状態等を確認します。金融原文・予約原本の本文を共通確認一覧へ転載しません。各分野の台帳から取得する次行動は、ID・版・状態と表示許可済みの本文・期限です。大学制限本文や未許可の本文は共通表示の対象外です。

Googleから本人のメールアドレスと検証状態を読み、設定した本人アカウントと一致するか確認します。OAuth tokenはAPIの認証に用います。集計用はCalendar読取り・Sheets編集・userinfo.email/openidを要求します。別の書込み用認証はこれらとcalendar.events.ownedを要求します。所有カレンダー全体の予定操作が可能なGoogle権限ですが、通常書込みは既存「移動・宿泊」に固定します。本人が個別確認した重複表示の統合は対応先の読戻し・元ID/版と確認済み対象に限定し、予約や元メールは変更しません。

保存先・保持・削除

本人Macの私的領域にOAuth client/token、取得cache、操作state、送信spool、保存読戻しreceiptを保持します。client/tokenのファイルは600、authディレクトリは700です。再送や応答喪失からの回収に必要な版・操作ID・履歴を保持します。自動消去期限と遠隔バックアップは未設定です。

確認一覧は本人の既存Google Sheetに保存します。閲覧権限はそのSheetの既存設定に従います。Gitには取得cache/state/spool/receipts、認証値、予定本文を保存しません。停止・権限取消・削除の依頼は担当が対象と権限を照合し、元のサービスと私的領域から処理します。Googleアカウントのアプリ許可を取り消すと、その認証による取得を継続できません。過去のSheet観測やlocal履歴の削除は別の処理です。

通信と利用範囲

このMac workerは認証と取得・確認一覧の保存・本人が依頼した旅程予約のカレンダー反映のためGoogleのOAuth/Calendar/Sheets APIへ通信します。本人がCodexの接続機能で一覧を確認する場合は、そのサービスと接続機能の利用条件も適用されます。この文書は他サービスのデータ保持条件を保証するものではありません。

公開案内のホスティングはGitHub Pagesです。GitHubは訪問者のIPアドレスをsecurity目的で記録します。案内ページに独自のアクセス解析・広告・追跡スクリプトは設置しません。本人の予定データや認証値をこの公開サイトへ送信する機能はありません。

アプリのコードに広告配信、データ販売、汎用モデル学習への転用機能はありません。Googleユーザーデータの利用はここに記載した予定・締切・次行動の確認と本人が依頼した操作の管理に限定します。Google API Services User Data PolicyのLimited Useを含む適用条件に従って運用します。
